# Web UI Principles

The rules the web pane must follow. They exist so the pane works on a phone, one-handed.

## Keep input low friction

Easy data entry. Prefer choices over text: buttons, chips, selectors, recent items. Do not put a text field anywhere except the chat box.

## Work one handed

The pane must be usable with one hand, on a phone. Controls big enough to press, near where the thumb is, nothing that needs a hover.

## Shortcut repetitive steps

Make a repeated action take fewer steps. Remember the last choice, offer the recent options, keep the state the user already gave.

## Be concise

Show each piece of information once. Do not repeat what is already on screen or already said.
